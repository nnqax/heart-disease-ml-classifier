# 🫀 Heart Disease Classification Models

A Machine Learning project created as part of the Girls Who Code (GWC) curriculum. This repository contains data preprocessing, label encoding, and predictive modeling for heart disease indicators using **Decision Tree** and **Random Forest** algorithms.

---

## 📌 Project Overview

This project uses the 2020 Heart Disease Indicators dataset to predict whether an individual is at risk for heart disease based on demographic and personal health features. 

It includes two standalone implementations:
1. **Decision Tree Classifier (`main.py`)**: Predicts heart disease risk using a single decision tree model.
2. **Random Forest Classifier (`forestClassifier of main.py`)**: Predicts heart disease risk using an ensemble random forest model.
